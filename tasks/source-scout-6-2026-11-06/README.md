## Method and gates, per route

1. **Terms first** (`terms_checks.csv`, six quotes re-checked raw, words in order; `routes.csv` has status/size/hash for 17 route URLs, re-run with `fetch_routes.py`). No term restricts reuse. FDA: "They are in the public domain and may be republished…". FIED: "Content is available under Creative Commons Attribution 4.0 unless otherwise noted" (cite NREL FIED, DOI 10.25984/2437657). EPA data licence (NEI): "all data produced by the U.S EPA is by default in the public domain". FTZ: data.gov record DOC-5426 carries the public-domain label (catalog metadata, not an ITA terms page). DOL: "Materials created by the federal government are generally part of the public domain…" (Wayback copy of the DOL copyright page; the live page is 403 from this network). USAspending: no restrictive term found; the terms page is a JavaScript app that cannot be read raw, so this is recorded as unverified-in-prose, not as a pass.
2. **FDA**: bulk zips from `accessdata.fda.gov/premarket/ftparea/` (Registration, registration_listing, Listing_PCD, listing_estabtypes, foiclass, estabtypes; SHA256 in `fda/counts.json`). **Trap found:** `ADDRESS_TYPE_ID` U is the *US agent's* address (a person's name) for a foreign firm; the frame uses type F (facility) only. Official_Correspondent, us_agent and contact_addresses were never downloaded; Owner_Operator was fetched in the first batch and deleted unused (personal-name risk). Code filter = regex on device *names* (`fda/build.py`: plastic, polymer, silicone, polyethylene, rubber, latex, vinyl, PTFE, hydrogel, …) excluding IVD panels CH HE IM MI PA TX; known-answer asserts in the builder. It is a keyword filter on names, not a material class.
3. **FIED**: 183 MB CSV from `data.openei.org/files/6158/`; the frame is facility grain (registryID); `frs_name`/`frs_street` come from the T2 ECHO exporter cache and are matched in addition to the abbreviated FIED name (`CHEML TECH RBR` → `CHEM-TECH RUBBER, INC`). Registry links (FRS) are matched first. **NEI 2020**: landing page 200; `2020_nei_facility_summary.zip` (29 MB) and `2020nei_facility_process_byregions.zip` (157 MB) resolve; the 2023 NEI page is 404. Not sampled: FIED carries the same facility keys with NAICS and address in one keyless file.
4. **FTZ**: the legacy `ita-web.ita.doc.gov/ia/FTZManufac.nsf` no longer resolves (000); OFIS `ManufacturingDB` is a Razor page whose form POST 302-redirects to `DetailHTSUS`, which loads JSON from `?handler=LoadPartsByHTSUS` (antiforgery cookie + header). `ftz/fetch_approvals.py` queries each four-digit heading 3901–3926 and 4001–4017 once (43 requests, 1/s). The query returns every approval with *any* part under the heading, so the frame keeps only approvals whose part is a finished **Product** in ch. 39/40 (a ch. 39 *Component* means plastic is an input to something else: STIHL, Garmin).
5. **DOL**: **silent-loss catch.** DuckDB `read_xlsx` returned 118,580 of the sheet's 563,689 `<row>` elements with no error. An independent stream of the sheet XML shows 118,581 rows carrying a value (header + 118,580) and ~445k blank styled rows; `openpyxl` read-only agrees, so 118,580 is the real case count (`dol/xlsx_to_csv.py` keeps only employer, address, NAICS, worksite and status columns; worker, attorney, preparer and POC fields are never read). Some worksite-address fields hold the employer name instead of a street (Auriga Polymers, BDG Wrap-Tite): unusable for establishment verification, left STILL_UNCERTAIN.
6. **USAspending**: `POST /api/v2/search/spending_by_category/recipient/` (the true bulk archive is not NAICS-filterable); NAICS filter needs 2/4/6-digit codes, so 326 became 3261+3262; recipient address = SAM-registered address from `/api/v2/recipient/{id}/`.
7. **Dedupe** (`common.py`): registry link first (FRS, UEI, FDA_FEI against `data/registry_links.csv`), then `atlas.dedupe` name key / street key / trade-name substring, all shards; DUPLICATE_OF only for a registry link or one exact street+locality site (FTZ: exact normalized name, organization grain). A held parent alone never makes a site a duplicate. The T1 site corpus (own pages of held orgs) was grepped for each unmatched street: 3 DOL hits (Newell Brands, Chevron Phillips at `cpchem.com/locations`, FilmTec at a DuPont page), left STILL_UNCERTAIN with the corpus URL in `corpus_street_hit`.
8. **Personal data**: no worker/attorney/preparer/POC/phone/e-mail columns; the address quote is a ≤110-character window with phone and e-mail redacted; every CSV cell is scrubbed on write (`common.scrub`) after a directory URL slug carried a phone number.
