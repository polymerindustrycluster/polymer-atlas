# Lane t2-8 packet: PIC-12 capability wave, tranche 2 (2026-11-01)

**This is a packet, not a data change.** Lane t2-8 never edits `data/`, allocates IDs, commits or pushes. Every row in `packet.csv` is class `own_site`, carries the exact URL and a quote of 25 words or fewer, and each quote was re-checked programmatically as a substring of the page text I fetched (whitespace-normalised: zero-width characters ignored, space before punctuation closed, typographic quotes/dashes folded). All fetches were curl through the configured proxy with `--cacert /root/.ccr/ca-bundle.crt`; WebFetch was not used; no user-agent changes, no TLS bypass, no captcha handling. Org-scope rows use the ORG id as `record_id`. Fetched text and helper scripts are in `/tmp/claude-0/wave/t2_lane8/` (outside the repo). Vocabulary: `docs/schema/vocab.json` (v1.7.6); every in-vocab value was validated against it by script.

Assignment: `t2_lane8_assignment.csv`, 54 site rows (Ashtabula, Cuyahoga, Geauga, Lake, Lorain, Mahoning, Medina, Portage, Stark, Summit, Trumbull, Wayne). All 54 are `active` in `data/sites_OH.csv` and the assignment county matches the data county on every row. The repo HEAD at lane start was `c0192b8`, not the wave's pinned `665e5c5`; nothing here depends on that difference.
