### SCHEMA constraints that limited the proposals

1. **Degree rows only** (4.11): certificate/center/training/lab/course/apprenticeship rows get no IPEDS value even where they carry a cip_code; they are marked `join-key lead; institution page needed`. Certificate rows with an `ipeds_listing` CIP show the IPEDS count only inside `proposal_reason` as reference.
2. **Keyed pull needs a cip_code on the row**: degree rows with an empty cip_code are `join-key lead; institution page needed`; `candidate_polymer_cips_at_institution_2024` lists what IPEDS shows at the UNITID, informational only (a CIP must come from the catalog or be recorded as an `ipeds_listing` pair).
3. **Never estimated; `latest_completions` requires `completions_year`**: nothing is proposed when the mapped levels have zero 2024 completions, and `first_year_awarded` is withheld when completions already exist at the window floor (2011).
4. **IPEDS is a join key, never program evidence** (4.6 `ipeds_unitid`, 4.11 Lakeland rule): a proposal asserts a count at a CIP, not that the program exists; the held row's own-page evidence stays the basis.
5. **CIP-grain, not program-grain**: counts cover the whole CIP at the institution at the row's levels. For `14.1801` rows (Materials Engineering) this is the whole MSE-type count, not the polymer track (see `cip_scope_caveat`).
6. **The key is UNITID x CIP, not x level**: the proposed count is the first-major total over all detail award levels at that key (incl. post-baccalaureate certificates; flagged in `includes_postbacc_cert_2024`), which reproduces every held value that matches. Whether a row's own `level` set should narrow the count is not defined in SCHEMA; `level_alignment` and `row_level_completions_2024` show the narrower view without proposing it (an integrator/owner call).
7. `last_year_awarded` here means *latest year observed with completions in the pull window*; with `awarding_in_completions_year=yes` it is not a closure claim.

## 5. Caveats

- IPEDS reports by institution x CIP; it does not name programs, and a CIP can be assigned to a program whose own catalog never mentions polymers (Lakeland rule). Sinclair CC reported 28 certificate completions in AY2023-24 for a program its catalog discontinued: completions can lag liveness.
- C2024_A is provisional; counts can change at final release. Held rows carrying 2024 values were drawn from the same release.
- Multi-campus systems report under separate UNITIDs (parent vs branch); a lead may be an existing Atlas institution under another UNITID - run the AGENTS.md section 3 dedupe checks before any record.
- 14.1801 / 40.1001 counts are whole-field counts and say nothing about polymer content. They are carried because held degree rows use 14.1801.
- `first_year_awarded` is bounded by the 2011 window floor and by CIP re-coding; a program re-coded to another CIP appears as a start.
- Lead state-priority uses a QCEW NAICS 326 gap proxy computed from repo files at run time; it orders review effort only.
- No personal data is involved; institution website is the HD2024 public institutional URL (a pointer, not program evidence).
