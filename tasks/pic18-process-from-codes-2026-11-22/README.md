Lane `atlas-w22-process-inhand` (Claude Sonnet 5.5), controller thr_9i2c6byhcz. **Leads only: no process is filled from a code, nothing under `data/` changed, no PR.** This supersedes the first brief (fill at a low tier) and my earlier packet-and-schema-proposal draft, per the owner ruling relayed by the controller on 2026-11-22: SCHEMA 2.4 stands, and a NAICS code or NESHAP/NSPS subpart is a lead for a researcher, not a process. Cross-family review is the controller's.

## What is here
`leads.csv`: **16 lead rows on 15 organizations** (unit: PIC-18 organization rows with unknown process, 322; each has one active tier A–C Ohio site in the 333-site frame). One row per (site, code, filing class): record id, the code and its title (`data/ref_codes.csv`), the filing by lake file and row (`src_path`, `src_row`, `src_key`), the filing's own name and street as filed, how the name matched, the suggested SCHEMA 3.1 term, and the table tier. 13 organizations from OSHA ITA Form 300A establishment filings, 3 from SAM entity registrations (separate class: entity grain). Suggested terms by organization: polymerization 5, extrusion_profile 3, mold_tool_making 3, foam_production_unspecified 2, laminating 2, custom_compounding 1 (an organization can carry two). `table_tier` T1 = the NAICS title names the activity (6 organizations); T2 = the title names a product or material and the process is only the usual route (9). The suggestion map is `codes.py`; a suggestion is a pointer for the researcher, nothing more.

## Match rule (replayed by `check.py` from the lake, not from the scratch pair flags)
Street: the repo's `same_street` (civic number, no suite conflict). Locality: Ohio and same ZIP5 or city. Name: a held name (`site_name_key`, `org_name_fields`) equals the filed name after the repo's locality strip, spacing folded. A street match with no held name is not a lead (53 more sites, not listed). Rows older than CY2023 are kept but dated (`newest_year`), because a lead's age is the researcher's call.

ITA plus SAM give 106 of the 127; the other 21 rest on inspection, ICIS-Air or FRS alone and are not in `leads.csv` (a lead from those classes would be a regulator-assigned or registry code, not one the establishment filed; say if you want them listed too).
