Copied byte-for-byte from the PIC Design System (`project/assets/`, 2026-11-02):
`pic-mark-color.svg`, `pic-mark-white.svg` (the molecule mark), `pic-logo-white-no-tagline.svg` and

Usage follows the brand guide: the molecule may stand alone as a design element (header, favicon);

dark. Lato (`../fonts/lato-*.woff2`, SIL OFL 1.1, `../fonts/lato-OFL.txt`) is PIC's web typeface.
